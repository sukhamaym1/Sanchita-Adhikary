Why does login fail after some time?

GitHub Personal Access Tokens expire automatically after 30 days by default. When a token expires, GitHub rejects it.

How to get a long-lasting token:

  1. Click the button below to open GitHub token page.
  2. Change Expiration to 90 days or No expiration.
  3. Ensure the repo box is checked.
  4. Click Generate token and copy it here.
